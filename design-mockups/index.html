Easy Rename, rebuilt around the main quest.

The single thing you're here to do is rename matched subtitle files. Today that action is buried in a left rail under a wall of regex. This pass makes rename the hero, demotes the regex power-tooling, kills the redundant preview tables, and ships a real depth-based visual system — light & dark.

What changes vs. today

Rename button buried in the left rail → Hero CTA, always visible (sticky bar / rail top). The main quest is one click.
Regex settings dominate the top of the screen → Collapsed into a Pattern pill; Auto-detect stays one tap. Power tooling, demoted.
Two redundant “Videos / Subtitles” index tables → Removed. The index badge on every row + a 3-line live preview inside Pattern cover the same need.
Emoji icons (📂 🗂️ ＋) → Crisp inline SVG iconography, recolored per file type and state.
Flat cards, no hierarchy, generic blue → Depth elevation: raised primary button, inset troughs, composite shadows, OKLCH neutrals.
Light theme only → Light + dark with a toggle; both first-class.
Plain “X videos · Y subtitles” text → Match progress with a real bar + count badges for unmatched/stray state.
