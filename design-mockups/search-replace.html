New rename mode · PowerRename-style find & replace

Search & Replace — a second mode for Easy Rename.

The existing Match Subtitles mode stays as-is. This adds a sibling mode that does plain find/replace (or regex) across all files in the loaded folder, with a live Original → Renamed preview. It reuses the same rename engine, conflict policy, undo, and report — only the matching logic and controls are new.

Shares the generic rename & undo engine Regex · case-sensitive · apply-to (name / ext / both) Live Original → Renamed preview Last run auto-saved, restored on launch All files, recursive · folders excluded

What the mode adds vs. today

One rename strategy (subtitle → video stem) → Two modes behind a topbar switch. Match Subtitles unchanged; Search & Replace is new.
Media-only file filter → Search & Replace sees all files (recursive); folders are excluded from the operating set.
No string replacement → buildSearchReplacePlan() — regex or literal, case-sensitive option, apply-to scope. Feeds the same RenameOp[] engine.
Pattern preview (5-line extraction) → Original (N) → Renamed (M) two-column table with live match / conflict counts.
No cross-launch memory of inputs → Last-used search / replace / options / mode are auto-saved and restored on next launch.
